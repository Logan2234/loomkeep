# Archive

Point-in-time documents: audits and migration notes written against one
commit, kept for their reasoning but **not maintained**. Their figures, line
numbers and file paths describe the code as it was then — read the code, not
these, for the current state.

What stays one level up, in `docs/`, is maintained and holds today:
decisions (`adr/`), the data model, the messaging guide and the mobile plan.
