**What comes in:** your anime list, with status, progress, score, start and
finish dates, notes, and the storage you set (as ownership).

**Not imported:** manga lists, rewatch counts, tags and priority.

<Steps>

1. On MyAnimeList, open [the export page](https://myanimelist.net/panel.php?go=export)
   and export your **anime** list.
2. In Loomkeep, open **Settings › Import › MyAnimeList** and drop the `.xml`
   file (unzip it first if it came as `.gz`).
3. Review and import: see [how an import works](/guide/imports/#how-an-import-works).

</Steps>

Anime are matched by title against TMDB, the catalogue Loomkeep uses for
anime: only an exact title is matched on its own, the rest waits for you in
the review. TMDB files a whole show where MyAnimeList lists each season
apart, so a sequel season usually needs matching by hand, and then comes in
with its status alone: tick its episodes on the show's page.
