**What comes in:** your anime list, with progress, notes and ownership.
Manga lists aren't imported yet.

1. On MyAnimeList, open [the export page](https://myanimelist.net/panel.php?go=export)
   and export your **anime** list.
2. In Loomkeep, open **Settings › Import › MyAnimeList** and drop the `.xml`
   file (unzip it first if it came as `.gz`).
3. Review and import: see [how an import works](/guide/imports/#how-an-import-works).

Anime are matched through AniList, the catalogue Loomkeep uses for anime,
which knows MyAnimeList's ids.
