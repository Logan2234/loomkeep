The AniList import is off for now. Loomkeep used to read your list through
AniList's API, whose terms don't allow a tracker like Loomkeep to use it, and
anime now come from TMDB like series. It will come back reading the data
export AniList gives you (**Settings › Account › GDPR Data Download**), with
each anime matched on TMDB.

Until then, export your list from [MyAnimeList](/guide/imports/myanimelist/)
if you keep one there too.
