These sources are planned. Each will get its own page once it ships.

| Source        | Domain      | What it will bring                                      |
| ------------- | ----------- | ------------------------------------------------------- |
| Letterboxd    | Films       | Diary, ratings and watchlist (ZIP export)               |
| Kitsu         | Anime       | Anime list, matched through MyAnimeList and AniList ids |
| LibraryThing  | Books       | Library and reading history                             |
| BookWyrm      | Books       | Library and reading history                             |
| Spotify       | Podcasts    | Followed podcasts                                       |
| OPML          | Podcasts    | Subscriptions from Apple Podcasts, Pocket Casts…        |
| BoardGameGeek | Board games | Collection and plays (CSV export)                       |

Podcasts and board games are domains Loomkeep doesn't track yet: their
imports come with them.
