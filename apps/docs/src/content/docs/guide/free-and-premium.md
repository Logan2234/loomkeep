**There is no premium plan yet: every account has everything below, for
free.** This page lists what will differ once it launches, so nothing comes
as a surprise. It is kept up to date as features are added.

Premium will sell comfort and higher limits. It never takes away what you
already have: tracking, history, imports and exports stay free.

## What differs

| Feature                                               | Free           | Premium                 |
| ----------------------------------------------------- | -------------- | ----------------------- |
| Films, series, anime, games, books                    | ✓              | ✓                       |
| Music, and podcasts and board games once they arrive  | —              | ✓, in early access      |
| [Imports](/guide/imports/)                            | One per domain | Unlimited               |
| Saved library views                                   | 3              | 24                      |
| Release digest                                        | Weekly         | Daily or weekly         |
| [Stats](#advanced-stats)                              | ✓              | ✓, plus advanced stats  |
| [Calendar and feed links](/guide/calendar-and-feeds/) | —              | ✓                       |
| Navigation styles                                     | Marquee        | Marquee, Dock and Board |
| [API](/api/) requests per minute                      | 60             | 300                     |

"One import per domain" means one successful import: a second source for the
same domain, or importing the same one again, would need premium. The API
limits are loomkeep.app's; a self-hosted instance sets its own.

## Free, with no limit

Everything else: tracking in every free domain, episodes, sessions,
rewatches and cycles, ratings and notes, lists, the calendar page,
notifications, social features, achievements, the full
[data export](/guide/your-data/), personal API keys and
[two-factor authentication](/guide/security/).

## Advanced stats

The stats page stays free. Premium adds, for each domain:

- **Overall**: rating distribution, decades, and what you own.
- **Films and series**: viewing over time, genres, longest and shortest
  film, films rewatched, longest binge, and shows paused or forgotten.
- **Games**: most played games, platforms and genres, and your average
  rating per platform and per genre.
- **Books**: longest and shortest book, authors read most, and how many
  authors.
- **Music**: most listened artists, and albums versus singles and EPs.
- **Social**, when the instance has it: your reviews, comments, reactions
  and followers over time, and how your ratings compare with everyone
  else's.

## On a self-hosted instance

A self-hosted instance runs the same features. Once premium launches, a
yearly license key makes every account of the instance premium: see
[Premium edition](/self-hosting/premium/).
