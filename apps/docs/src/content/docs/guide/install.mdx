import { Steps, TabItem, Tabs } from "@astrojs/starlight/components";

Loomkeep is a web app you can install: it then opens in its own window,
without the browser's bars, and gets a home screen or dock icon. There is
nothing to download from a store.

<Tabs>
  <TabItem label="iPhone, iPad">
    <Steps>

    1. Open [loomkeep.app](https://loomkeep.app) in **Safari**.
    2. Tap **Share**, then **Add to Home Screen**.
    3. Tap **Add**.

    </Steps>

    On iPhone and iPad, **push notifications only work once Loomkeep is
    installed** this way.

  </TabItem>
  <TabItem label="Android">
    <Steps>

    1. Open [loomkeep.app](https://loomkeep.app) in **Chrome**.
    2. Open the **⋮** menu and choose **Install app** (or **Add to Home
       screen**).
    3. Confirm.

    </Steps>

  </TabItem>
  <TabItem label="Computer">
    In **Chrome** or **Edge**, open [loomkeep.app](https://loomkeep.app) and
    click the install icon at the right end of the address bar, or choose
    **Install Loomkeep** in the browser's menu.

    Firefox doesn't install web apps on desktop: Loomkeep works in a tab as
    usual.

  </TabItem>
</Tabs>

## Notifications

Once installed, turn on push notifications in **Settings › Communications**
to hear about new episodes, replies and more even with the app closed. What
each alert does is in [Notifications](/guide/notifications/).

On a self-hosted instance, use your own address instead of loomkeep.app.
