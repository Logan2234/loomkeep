## Open source: AGPL-3.0

Loomkeep is free software under the
[GNU Affero General Public License v3.0](https://github.com/Logan2234/loomkeep/blob/main/LICENSE).
You can use it, study it, change it and run it, for yourself or for others.

The one obligation that differs from most licenses: if you run a **modified**
Loomkeep for other people over the network, you must offer them the source
of your version, changes included. Running it unmodified asks nothing of
you.

## The premium edition: `ee/`

The files in directories named `ee/` (`apps/api/src/ee`,
`apps/web/src/lib/ee`) are under the
[Loomkeep EE License](https://github.com/Logan2234/loomkeep/blob/main/LICENSE-EE)
instead. Their code is public and ships in every build, but using those
features in production takes a license key. **Until the premium offer
launches, they stay on for everyone without one**: see
[Premium edition](/self-hosting/premium/).

What stays free, and why, is set out in the
[open-core decision record](https://github.com/Logan2234/loomkeep/blob/main/docs/adr/0001-open-core-agpl.md)
(in French). In short: premium is sold as comfort and higher limits, never
as software only loomkeep.app can run, and stays available to self-hosted
instances with a key.

## Contributions

Contributors sign a
[Contributor License Agreement](https://github.com/Logan2234/loomkeep/blob/main/CLA.md)
before their first pull request is merged. They keep the copyright; the
agreement lets the project ship their code under both licenses above.

## Catalogue data

Titles, covers and details come from catalogues with licenses of their own,
which stay in force:

| Catalogue                                  | Terms                                               |
| ------------------------------------------ | --------------------------------------------------- |
| [TMDB](https://www.themoviedb.org)         | TMDB's terms of use                                 |
| [AniList](https://anilist.co)              | AniList's terms of use                              |
| [IGDB](https://www.igdb.com)               | IGDB's terms of use                                 |
| [Open Library](https://openlibrary.org)    | Catalogue data under CC0                            |
| [MusicBrainz](https://musicbrainz.org)     | Core data under CC0, the rest under CC BY-NC-SA 3.0 |
| [OMDb](https://www.omdbapi.com) (optional) | CC BY-NC 4.0                                        |
