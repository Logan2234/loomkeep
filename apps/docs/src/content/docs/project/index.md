Loomkeep is a tracker for series, films, anime, games, books and music,
built as a replacement for TV Time you fully own. It is open source, runs on
[loomkeep.app](https://loomkeep.app) or on your own server, and is made and
hosted by one person, [@Logan2234](https://github.com/Logan2234), as a side
project: no investor, nothing to sell your data to.

## Follow and shape it

- **[Changelog](https://feedback.loomkeep.app/changelog)**: what each release
  brings. Subscribe from your account settings to get it by email.
- **[Roadmap](https://feedback.loomkeep.app/roadmap)**: what's planned and
  under way.
- **[Feature requests](https://feedback.loomkeep.app/board/feature-requests)**:
  propose an idea, or vote for one.
- **[Status](https://status.loomkeep.app)**: whether loomkeep.app is up.

## Getting help

| You have…                           | Go to                                                                                                                            |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| A bug in the app                    | The [bug reports board](https://feedback.loomkeep.app/board/bug-reports)                                                         |
| A problem running your own instance | A [GitHub issue](https://github.com/Logan2234/loomkeep/issues/new/choose): see [Troubleshooting](/self-hosting/troubleshooting/) |
| A security issue                    | A private report: see [Security](/project/security/)                                                                             |
| A question about contributing       | A [GitHub issue](https://github.com/Logan2234/loomkeep/issues/new/choose), "Other" template                                      |

## Supporting the project

the server and the time:
[GitHub Sponsors](https://github.com/sponsors/Logan2234),
[Liberapay](https://liberapay.com/loomkeep/donate),
[Ko-fi](https://ko-fi.com/loomkeep) or
[Buy Me a Coffee](https://www.buymeacoffee.com/loomkeep).
Contributing helps too: see [Contributing](/project/contributing/).
