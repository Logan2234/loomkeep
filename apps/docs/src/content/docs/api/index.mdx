The Loomkeep API gives read access to your own account: your library across
video, games, books and music, your lists, upcoming episodes, stats, reviews,
profile, notifications and a full data export.

It is a plain JSON API over HTTPS, authenticated with a personal API key you
create yourself. Each key only reaches the resources you grant it, and you can
revoke it at any time.

## Base URL

```
https://loomkeep.app/api/v1
```

On a self-hosted instance, use your own address: `https://<your-instance>/api/v1`.
Each instance also serves the exact contract it runs at
`/api/v1/openapi.json`.

## Quick start

1. In Loomkeep, open **Settings › Integrations** and create an API key. Give it
   the resources your tool needs, then copy it: it is only shown once.
2. Call the API with the key in the `Authorization` header:

   ```sh
   curl -H "Authorization: Bearer lk_…" https://loomkeep.app/api/v1/me
   ```

   `/v1/me` works with any key and tells you which account and key you are
   using, and your rate limit.

3. Browse the [API reference](/api/reference/) for every endpoint, or try them from
   there with your key.
